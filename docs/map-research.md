# Reference layout study — September 2026

The requested versions are MW2 (2009) Afghan; Ocarina of Time's child-era Market; Battlefield 3 Operation Metro; GTA IV Star Junction; THPS1 School; Joppa; No Mercy's **starting apartment roof**; Portal 1's final GLaDOS chamber; the **classic river Roshan pit**; and JSRF Shibuya Terminal. The user confirmed the ambiguous versions during this study.

## Can these be matched exactly?

**Not from the evidence collected here.** Overhead guides and screenshots establish landmarks and route relationships, but do not provide reliable world coordinates, collision meshes, dimensions, or complete elevation measurements. This update is a closer, reference-based reconstruction, **not a verified 1:1 recreation**. All coordinates and heights in `src/layouts.js` are hand-estimated prototype units. No original game map files or art assets were imported.

The references below were searched online. The Afghan, Market, School, Joppa, Star Junction, Metro, apartment roof, Portal, Shibuya, and old Roshan images were also inspected directly. Reference pictures are retained only in the task's scratch folder, not redistributed in this repository.

## Vertical movement and visibility implementation

- Stairs have actual collidable treads; a grounded player automatically steps up rises of at most 0.32 units. Larger obstacles still require jumping.
- Floors are separate slabs. A player can move underneath an elevated bridge, descend through an opening, and land on the floor below. Solid walls and ceiling undersides block movement and shots.
- Rotated boxes share the same transforms for visuals, movement collision, hitscan and navigation.
- AI navigation records multiple walkable elevations in each map column, allowing routes over and under the same structure.
- The pit interior is a shared visibility zone. The opponent mesh and remote tracer are hidden when the players are on opposite sides; the AI uses the same boundary when deciding whether it can see or fire. A dark curtain marks the entrance. **Blind fire can still hit**, and sound remains audible.
- The pit currently hides entities rather than implementing a full terrain fog-of-war system. The server still sends both player states, so this is a gameplay visibility feature, not an anti-cheat boundary.

## What a verified exact reconstruction would require

For a true 1:1 result, the next input would need to be original map geometry/collision data or a measured survey from the specified versions, plus exact crop boundaries. Public screenshots alone do not justify a claim of exact scale. These reference URLs and the editable layouts make that next pass possible without disguising the current uncertainty.
